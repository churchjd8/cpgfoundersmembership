Paste these into Kajabi's email editor in **source / code view** (the `< >`
button), not the visual editor. Copy the whole file.

Merge field is `{{first_name}}`.

`_preview-all.html` renders all five in a browser so you can proof them before
pasting. It is not for pasting into Kajabi.

These are body fragments only, no `<html>` or `<body>` wrapper, because Kajabi
supplies its own shell plus the unsubscribe footer. All styling is inline so it
survives every email client. Accent is #a56a16 to match the site.

Plain-text versions of the same copy are one directory up if you'd rather paste
into the visual editor instead.
